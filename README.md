# ИТ-Куб: бюро находок

> 🏆 **Хакатон «Мобил-ринг» • Кейс №4 «Бюро находок: Поиск и возврат вещей» • Номинация: Профи**  
> 📊 **Презентация проекта:** [`present.pptx`](present.pptx)  

Мобильное Android-приложение для учеников ИТ-Куба, чтобы посмотреть найденные в учебном центре вещи, безопасно вернуть их законным владельцам через PIN-код Safe Handover и общаться во встроенном P2P-чате. Серверная часть реализована на FastAPI со встроенной административной веб-панелью. Приложение работает по стандарту Offline-First и продолжает функционировать даже при отсутствии школьного интернета.

## Структура

```
backend/   — FastAPI + SQLite
mobile/    — Android (Java)
docs/      — дизайн-спека
```

## Запуск бэкенда

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

База `maindb.db` создаётся автоматически с одним админом `admin / admin` и 4 примерами вещей. Загружаемые фото лежат в `backend/uploads/`.

## Веб-админка

После запуска бэкенда открой `http://localhost:8000/` — редирект на `/admin-ui/`. Логин: `admin / admin`. Три вкладки: вещи (с фильтром по статусу), добавить вещь (с фото), заявки на возврат.

### Эндпоинты

Публичные:
- `GET /users/items/getaccept` — одобренные вещи
- `GET /users/items/getitem/{id}` — одна вещь
- `POST /users/claims` — отправить заявку на возврат

Под HTTP Basic auth (`admin/admin`):
- `GET /admin/items/getall`, `GET /admin/items/getapplic`
- `POST /admin/items`, `PUT /admin/items/{id}/status`
- `POST /upload` — загрузка фото
- `GET /admin/claims`, `PUT /admin/claims/{id}/status`

Swagger UI: `http://localhost:8000/docs`.

## Запуск мобилки

Открыть `mobile/` в Android Studio, запустить на эмуляторе.

Базовый URL зашит в `app/build.gradle.kts` как `BASE_URL = http://10.0.2.2:8000/` — это адрес хост-машины из эмулятора. Если бэкенд на другом хосте — меняй там.

### Демо-режим

При недоступности бэкенда (таймаут 2с) приложение читает фикстуры из `app/src/main/assets/seed_items.json`, показывает баннер "Демо-режим (без сети)" и в форме заявки выводит тост "Демо-режим: заявка не отправлена".

## Сценарии для проверки

**Онлайн:**
1. Запустить бэкенд.
2. Открыть приложение → список вещей, поиск по месту/описанию.
3. Тап на карточку → детали.
4. "Это моя вещь!" → форма → отправить.
5. `curl -u admin:admin http://localhost:8000/admin/claims` — заявка появилась.

**Оффлайн:**
1. Бэкенд выключен.
2. Открыть приложение → баннер "Демо-режим", список из 8 фикстур.
3. Поиск работает по локальным данным.
4. Форма заявки выводит демо-тост и не отправляет.
